4. CLASSIFICATION ANALYSIS
================================================================================

METRIC DEFINITIONS:
  - Accuracy: Percentage of correct predictions
    Formula: (TP + TN) / (TP + TN + FP + FN)
  
  - Precision: When model predicts class, how often correct
    Formula: TP / (TP + FP)
  
  - Recall: Of actual class, how many did we catch
    Formula: TP / (TP + FN)
  
  - F1-Score: Harmonic mean of precision and recall
    Formula: 2 × (Precision × Recall) / (Precision + Recall)

TEMPERATURE RESULTS:
  - 97.97% accuracy means 13 out of 395 samples misclassified
  - Errors are minor - typically between adjacent classes (Low↔Medium or Medium↔High)
  - No extreme misclassifications (Low↔High)
  - HIGH class has 99.2% accuracy
  - Real-world: 98 out of 100 predictions correct

PRECIPITATION RESULTS:
  - 50.13% accuracy means 197 out of 395 samples misclassified
  - Much harder to predict - sporadic rainfall patterns
  - HIGH class has 71.8% accuracy - useful for rain alerts
  - MEDIUM class only 8.8% accuracy - overlaps with other classes
  - Precision 67.14% means when we predict HIGH, correct 67% of time

ANTICIPATED QUESTIONS:

Q1: "Why is temperature 97.97% but precipitation only 50.13%?"
A: Temperature has clear seasonal patterns (easy to learn). Precipitation is 
   sporadic and influenced by many atmospheric factors not in our dataset 
   (humidity, pressure, wind). Temperature naturally separates into 3 classes, 
   while precipitation distribution is multi-modal and imbalanced.

Q2: "Is 97.97% accuracy realistic or did you overfit?"
A: It's realistic because:
   - We used time-series split (no future data leakage)
   - Temperature patterns are genuinely predictable
   - Errors are small (±1 class, not extreme mispredictions)
   - Different models agree on predictions (ensemble stability)
   - Only 13 errors out of 395 samples

Q3: "Is 50.13% accuracy good?"
A: It depends on use case:
   - Baseline would be 33% (random guess for 3 classes) - we're 51% better
   - High precipitation alert: 71.8% accurate - good for warnings
   - Overall: Needs improvement but demonstrates real-world challenges
   - With more features: Could likely improve to 70%+

Q4: "Why use 5 models instead of just 1?"
A: Ensemble benefits:
   - Diversity: Each model captures different patterns
   - Robustness: If one model wrong, others might be right
   - Stability: Less prone to overfitting
   - Performance: Usually beats any single model
   - Evidence: Temperature shows excellent stacking benefit

Q5: "Explain precision vs recall"
A: Precision (67.14% for precipitation HIGH):
   - "When I predict rain, how often am I correct?" - 67.14%
   - If you get 100 rain predictions, ~67 will be correct, ~33 false alarms
   
   Recall (50.13% for precipitation):
   - "Of actual rainy days, how many did I catch?" - 50.13%
   - If 100 rainy days occur, I catch ~50, miss ~50

Q6: "What does confusion matrix show?"
A: Cross-tabulation of actual vs predicted:
   - Diagonal = correct predictions
   - Off-diagonal = errors/confusions
   - Temperature: Mostly diagonal (good!)
   - Precipitation: Many off-diagonal (challenging!)

Q7: "Would you deploy this model?"
A: Temperature: YES - 97.97% accuracy acceptable for production
   Precipitation: MAYBE - needs monitoring and improvement
   
   Production requirements:
   - Temperature: Basic monitoring, retrain annually
   - Precipitation: Additional features, class balancing, frequent retraining

Q8: "What would you do to improve?"
A: For Temperature:
   - Collect more data
   - Add weather station features
   - Hyperparameter tuning
   
   For Precipitation:
   - Add atmospheric features (humidity, pressure, wind)
   - Handle class imbalance (oversampling/weighting)
   - Try different discretization (5 classes instead of 3)
   - Collect more low-precipitation samples
   - Use probabilistic predictions instead of hard classes
