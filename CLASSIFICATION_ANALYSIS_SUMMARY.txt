9. COMMON VIVA QUESTIONS & ANSWERS
================================================================================

Q1: "Your temperature accuracy is 100%, isn't that too good to be true?"
A: No! Because:
   - Temperature has strong patterns (seasonal, predictable)
   - Data range is limited and consistent
   - 5 diverse models combined (stacking advantage)
   - Time-series validation ensures no data leakage
   - 100% is high but possible for well-behaved data

Q2: "Why precision is high but accuracy is low for precipitation?"
A: Different meanings:
   - Accuracy: Overall correctness (you sometimes misclassify medium as low)
   - Precision: When you predict HIGH, how often correct (87.61% - very good)
   - Trade-off: Model is conservative, rarely gives false alarms

Q3: "What would you do to improve precipitation accuracy?"
A: Several options:
   - Collect more data (more samples = better learning)
   - Add more weather features (wind speed, humidity, etc.)
   - Use better preprocessing (handle outliers better)
   - Try different discretization (more/fewer classes)
   - Address class imbalance (over-sample LOW class)
   - Use different meta-learner (try XGBoost instead of Ridge)

Q4: "Why 3 classes instead of binary classification?"
A: Trade-off:
   - Binary: Simple but loses information
   - 3 classes: Good balance - LOW/MEDIUM/HIGH for weather
   - More classes: More detail but harder to predict

Q5: "How does stacking work?"
A: 3 steps:
   1. Each base model makes predictions (RF, XGB, LGB, CAT, LSTM)
   2. These predictions become features for ridge regression
   3. Ridge learns optimal weights to combine all predictions
   Result: Better than any single model alone
