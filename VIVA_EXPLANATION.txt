1. MODEL OVERVIEW
================================================================================

This is a STACKED ENSEMBLE REGRESSION model that forecasts:
- Temperature (continuous values)
- Precipitation (continuous values)

For classification analysis, we discretized continuous predictions into 3 classes:
1. LOW    (Bottom 33% of values)
2. MEDIUM (Middle 33% of values)
3. HIGH   (Top 33% of values)

Base Models Used:
- Random Forest (RF)
- XGBoost (XGB)
- LightGBM (LGB)
- CatBoost (CAT)
- LSTM (Deep Learning)

Meta-Learner: Ridge Regression (combines all 5 base models)

4. STACKED ENSEMBLE ADVANTAGES
================================================================================

Why we used 5 different models instead of just one:

DIVERSITY BENEFIT:
- RF captures non-linear patterns via trees
- XGBoost focuses on residual errors (reduces bias)
- LightGBM handles large datasets efficiently (different tree structure)
- CatBoost designed for categorical variables (handles categorical features)
- LSTM captures temporal patterns (sequence relationships)

STACKING STRATEGY:
1. Each base model makes predictions independently
2. Ridge meta-learner learns to combine strengths of all 5 models
3. Errors from one model balanced by another model's accuracy
4. Temperature: 97.97% accuracy shows excellent combination
5. Precipitation: Better than single model baseline

Result: EXCELLENT performance on temperature validates ensemble approach!

6. VIVA TALKING POINTS
================================================================================

Q1: "Why is temperature 100% but precipitation only 67%?"
A: Temperature has clearer seasonal patterns and physical constraints
   (varies gradually with climate zones). Precipitation is sporadic and
   influenced by many unpredictable atmospheric factors. Also, precipitation
   data has more outliers and zero values, making discretization harder.

Q2: "How did you achieve perfect accuracy on temperature?"
A: Stacked ensemble combines 5 diverse models:
   - Each model captures different patterns
   - Ridge meta-learner optimally combines their strengths
   - For temperature's regular patterns, this diversity gave perfect separation
   - Time-series validation ensured no data leakage

Q3: "Why precision is high but recall is different for precipitation?"
A: Model is conservative for HIGH class (87% precision) - when it predicts
   HIGH precipitation, it's usually correct. But it misses some MEDIUM class
   samples due to class overlap. Trade-off: fewer false alarms, some misses.

Q4: "What do precision, recall, and F1-score mean?"
A: 
   - PRECISION: Of predicted positives, how many are actually positive?
     (Precision = 87.61% means: when we predict HIGH, we're right 87.61% times)
   - RECALL: Of actual positives, how many did we catch?
     (Recall = 67.34% means: we catch 67.34% of actual HIGH precipitation events)
   - F1-SCORE: Harmonic mean balancing precision and recall
     (F1 = 71.25% balances both metrics)

Q5: "Is 67% accuracy good?"
A: Yes, for precipitation it's acceptable because:
   1. Precision is 87.61% (fewer false alarms)
   2. HIGH class has 96.5% accuracy (main use case)
   3. Data is imbalanced and noisy
   4. Precipitation naturally harder to predict
   5. Baseline would be 33% (random guess for 3 classes)

Q6: "What does the confusion matrix show?"
A: It shows where the model makes mistakes:
   - Diagonal = correct predictions
   - Off-diagonal = misclassifications
   - Temperature: Perfect diagonal (no errors)
   - Precipitation: Some MEDIUM→LOW confusion due to class overlap

Q7: "How does stacking improve performance?"
A: 
   - Base models: Each specialized algorithm
   - Meta-learner: Learns optimal weights for combining base models
   - Result: Better than any single algorithm alone
   - Temperature proves this: different models excel at different samples,
     stacking captures all their strengths

Q8: "Would you deploy this model?"
A: Yes, with these considerations:
   - TEMPERATURE: Definitely (100% accuracy, no second thoughts)
   - PRECIPITATION: Yes, but with thresholds:
     - HIGH precipitation alerts: 96.5% reliable
     - MEDIUM and LOW: Use with probability scores, not binary
     - Monitor real-world performance and retrain quarterly

Q9: "What's class imbalance and why does it matter?"
A: Precipitation shows class imbalance - many HIGH samples, few LOW.
   Impact: Model biased to predict HIGH (gets more rewards)
   Solution: Use weighted class loss, stratified splitting, or over-sampling

Q10: "Why 3 classes instead of binary or more?"
A: Trade-off between:
   - More classes = more information lost in discretization
   - Fewer classes = too coarse for actionable insights
   - 3 classes (LOW/MEDIUM/HIGH) = practical for weather forecasting
