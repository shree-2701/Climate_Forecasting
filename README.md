# Forecasting Precipitation and Temperature Evolution Patterns Under Climate Change

This project provides a complete, production-ready pipeline for forecasting temperature and precipitation using Random Forest, boosting, LSTM, stacking, and seasonal bias correction.

## Structure
- data/: Raw and processed climate data
- preprocessing/: Data cleaning and transformation scripts
- features/: Feature engineering scripts
- models/: Model training and stacking scripts
- evaluation/: Evaluation metrics and bias correction
- visualization/: Plotting and reporting scripts
- main.py: Pipeline entry point

## Requirements
- Python 3.8+
- See requirements.txt for dependencies

## Usage
1. Place your data in the data/ folder
2. Run main.py to execute the full pipeline
3. Results, models, and plots will be saved in the respective folders

## Deliverables
- Trained models
- Forecast results
- Evaluation tables
- Plots
